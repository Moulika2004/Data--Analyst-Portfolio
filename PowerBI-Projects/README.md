 📊 Data Professionals Survey Analysis

 📌 Project Overview

This project analyzes survey data from data professionals to understand trends
in job roles, salaries, programming language preferences, career challenges,
and job satisfaction.

An interactive dashboard was developed using Power BI to transform the survey
data into meaningful visual insights.

🎯 Objective

- Analyze the distribution of data professionals across countries.
- Compare salaries across different job roles.
- Identify the most popular programming languages.
- Understand the difficulty of entering the data industry.
- Analyze job and salary satisfaction among respondents.

 📂 Dataset

The dataset contains survey responses from data professionals.

Key information includes:
- Job role
- Country
- Salary
- Programming language preference
- Job satisfaction
- Work-life balance
- Difficulty of entering the data field


🧹 Data Cleaning & Analysis

The data was cleaned and transformed using Power Query before creating the
dashboard.

Key steps included:
- Handling missing and inconsistent values
- Cleaning categorical fields
- Transforming salary-related data
- Grouping job roles where required
- Creating calculated fields/measures
- Preparing the data for visualization

 📊 Dashboard

The Power BI dashboard provides an interactive view of the survey results.

The dashboard includes:
- Average salary
- Number of survey respondents
- Country-wise distribution
- Salary by job role
- Programming language preferences
- Difficulty of entering the data field
- Job and work-life satisfaction

 🔍 Key Insights

- Salary varies significantly across different data-related roles.
- Python is among the most preferred programming languages.
- Data professionals are distributed across multiple countries.
- Respondents have varying levels of difficulty when entering the data field.
- Job satisfaction and salary satisfaction differ across respondents.

 🛠️ Tools Used

- Power BI – Dashboard and visualization
- Power Query – Data cleaning and transformation
- DAX – Calculations and measures
- Excel/CSV – Dataset
